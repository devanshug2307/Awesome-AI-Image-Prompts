# Contributing

Thank you for helping improve Awesome AI Image Prompts. Contributions should
make the collection more useful, attributable, and safe to reuse.

## Before opening a pull request

1. Use an existing category, or explain why a new category is needed.
2. Add prompts that you wrote yourself or for which you can provide a reliable
   public source and attribution.
3. Do not submit private, copyrighted, or paywalled prompt content without
   permission from its owner.
4. Do not include personal data, deceptive instructions, or material that
   violates the applicable model provider's policies.
5. Use descriptive titles and state the intended subject, style, and format.

## Prompt format

Each prompt should include a title, prompt text, and a source link when it is
adapted from public work. Example images must be linkable and permitted for
display. Please avoid claims of guaranteed results: image models can vary by
version, settings, and inputs.

## Review process

Maintainers review pull requests for attribution, duplication, clarity,
category fit, and repository style. Submitting a pull request does not
guarantee inclusion. By contributing, you confirm that you have the right to
submit the content under this repository's license.
